Procedure 

Open Visual Studio Code. 

Create a new Angular project using the command: ng new user-profile-project 

Navigate to the project folder:  cd user-profile-project 

Generate a new component: ng generate component user-profile 

Write the required code in the user-profile.ts and user-profile.html files. 

Import the child component into the parent component. 

Use event binding to receive the event from the child component. 

Run the application using: ng serve --open 

Click the Update Profile button and observe the updated user information.
