# MySQL Error 2002 (HY000) & Login Guide (Linux / GitHub Codespaces)

## 1. Error Kya Hai?
```text
ERROR 2002 (HY000): Can't connect to local MySQL server through socket '/var/run/mysqld/mysqld.sock' (13)
```
* **Kaaran:** Aapka MySQL server abhi band (stopped) hai ya socket file (`/var/run/mysqld/mysqld.sock`) ke liye proper permissions nahi hain.
* GitHub Codespaces ya Docker containers mein background services apne aap start nahi hoti hain, isliye pehle server ko manually start karna padta hai.

---

## 2. Error Kaise Thik Karein (Step-by-Step)

### Step 1: MySQL Service Start Karein
Terminal mein yeh command chalayein:
```bash
sudo service mysql start
```
*(Note: Agar `mysql` se kaam na kare, toh `sudo service mariadb start` try karein).*

### Step 2: Service Status Check Karein
Check karein ki server chalu hua ya nahi:
```bash
sudo service mysql status
```

### Step 3: Agar Socket Folder Missing Error Aaye
Agar service start karne par bhi error aaye, toh `/var/run/mysqld` folder banakar permissions dein:
```bash
sudo mkdir -p /var/run/mysqld
sudo chown mysql:mysql /var/run/mysqld
sudo service mysql start
```

---

## 3. MySQL Mein Login Kaise Karein (Password Setup)

Linux/Ubuntu aur GitHub Codespaces mein MySQL ke `root` user ka **default password khali (empty)** hota hai kyunki yeh `auth_socket` plugin use karta hai.

### Tarika A: Bina Password Ke Direct Login (Sabse Aasan)
```bash
sudo mysql
```
*(Isse aap seedha `mysql>` prompt ke andar pahunch jayenge).*

### Tarika B: `-p` Flag Ke Saath Login
```bash
sudo mysql -u root -p
```
* Jab `Enter password:` likha aaye, toh **kuch bhi type mat kijiye, bas seedha `Enter` key daba dijiye.**

---

## 4. Apna Khud Ka Password Kaise Set Karein

Agar aap chahte hain ki bina `sudo` ke normal `mysql -u root -p` aur apna password dalkar login karein:

1. Pehle `sudo mysql` chalakar MySQL ke andar jayein.
2. Yeh SQL commands chalayein (`apna_naya_password` ki jagah apna password likhein):

```sql
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'apna_naya_password';
FLUSH PRIVILEGES;
EXIT;
```

3. Ab aap normal tarike se login kar sakte hain:
```bash
mysql -u root -p
```
