3. Theory
A. Introduction to Angular Components
Angular components are the basic building blocks of an Angular application. Each component manages 
a specific part of the user interface.
A component generally consists of three main parts:
1. TypeScript File: Contains the component logic and data.
2. HTML File: Defines the structure of the user interface.
3. CSS File: Defines the design and appearance of the component.
B. What is Property Binding?
Property binding is a feature of Angular that allows us to transfer data from a parent component to a 
child component or bind values to HTML element properties.
It uses square brackets [ ] to bind properties.
Syntax:
<app-user-profile [name]="userName"></app-user-profile>
Here, userName is the property defined in the parent component, and name is the property received by 
the child component.
C. What is @Input() Decorator?
The @Input() decorator is used to receive data from a parent component into a child component.
Syntax:
@Input() name: string = '';
It allows the child component to receive values dynamically from its parent.
D. Parent and Child Components 
Parent Component:
 Contains the main user information.
 Sends data to the child component.
 Uses property binding to pass values.
Child Component:
 Receives data using the @Input() decorator.
 Displays the received information.
 Can be reused in different parts of an application.
4. Procedure
1. Open the existing Angular project in Visual Studio Code.
2. Check whether the user-profile component is already created.
3. Open the user-profile.ts file and import Input from @angular/core.
4. Define properties such as name, email, age and course using the @Input() decorator.
5. Open the user-profile.html file and add HTML elements to display the user information using 
interpolation.
6. Open the user-profile.css file and apply CSS styling to the profile section.
7. Open the app.ts file and import the UserProfile component.
8. Add the UserProfile component to the imports array of the parent component.
9. Define user information such as name, email, age and course in the parent component.
10. Open the app.html file and use the <app-user-profile> selector.
11. Apply property binding using square brackets [ ] to pass data from the parent component to the 
child component.
12. Run the application using the ng serve command.
13. Open the browser and check the output at http://localhost:4200/.
