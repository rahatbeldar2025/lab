Theory
1. Angular Forms
Angular Forms are used to collect and manage user input. They allow users to enter information such as 
name, email, password and other details. Angular provides two types of forms: Template-driven Forms 
and Reactive Forms.

2. Reactive Forms
Reactive Forms are a method of creating and managing forms in Angular using TypeScript. They 
provide better control over form data, validation and user input.
Reactive Forms use classes such as:
 FormGroup: Manages multiple form controls together.
 FormControl: Manages an individual input field.
 FormBuilder: Helps to create form groups and controls easily.

3. Form Validation
Form validation is the process of checking whether the data entered by the user is correct or not. It 
ensures that users provide valid and complete information before submitting the form.
For example:
 Name should not be empty.
 Email should follow a valid email format.
 Required fields must contain data.

4. Angular Validators
Angular provides built-in validators to validate user input. 
Important validators are:
a) Validators.required: Ensures that the input field is not empty.
b) Validators.email: Checks whether the entered email address follows a valid email format.
c) Validators.minLength(): Ensures that the input contains a minimum number of characters.
d) Validators.maxLength(): Ensures that the input does not exceed the maximum number of characters.

5. Form Submission
Form submission is the process of sending entered data for processing. In Angular, the (ngSubmit) event 
is used to call a function when the user submits the form.
In this lab, the onSubmit() function checks whether the form is valid. If all fields contain valid data, a 
success message is displayed.

6. Validation Error Messages
Validation error messages inform users when they enter incorrect or incomplete information. 
For example:
 Name is required.
 Name must contain at least 3 characters.
 Email is required.
 Enter a valid email address.
These messages help users correct their mistakes before submitting the form.

7. Advantages of Reactive Forms
1. Provides better control over form data.
2. Supports built-in form validation.
3. Makes complex forms easier to manage.
4. Displays validation errors easily.
5. Helps in creating reliable and user-friendly forms.
4. Procedure

Step 1: Create a new Angular component using the command:
ng generate component user-form
Step 2: Import ReactiveFormsModule in the user-form component.
Step 3: Create form controls for Name and Email.
Step 4: Apply validation using Validators.required, Validators.email and Validators.minLength.
Step 5: Display validation error messages when the user enters invalid data.
Step 6: Submit the form and display a success message when all fields are valid.
