Procedure
1. Open Visual Studio Code.
2. Create a new Angular project using the command: 
ng new user-profile-project
3. Navigate to the project folder: 
cd user-profile-project
4. Generate a new component: 
ng generate component user-profile
5. Write the required code in the user-profile.ts and user-profile.html files.
6. Import the child component into the parent component.
7. Use event binding to receive the event from the child component.
8. Run the application using: 
ng serve --open
9. Click the Update Profile button and observe the updated user information.
